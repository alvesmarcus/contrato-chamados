# Sistema de Chamados

O Sistema de Chamados tem como objetivo organizar o registro e o acompanhamento de solicitações de suporte técnico, facilitando o atendimento e o controle dos chamados.

Foi desenvolvida uma primeira API de chamados utilizando FastAPI, com armazenamento em memória, criação e consulta de chamados, busca por ID, filtro por status e validação automática dos dados. A aplicação foi testada por meio do Swagger e os arquivos foram versionados e enviados ao GitHub.
